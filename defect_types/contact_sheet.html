Defect type clusters

Castings grouped by what the trained model sees, not by any label. These groupings came from the 4096-dimensional feature vector behind the model's defective/good verdict.

What to look for. Scroll each cluster and ask one question: do these castings share a visible characteristic? A cluster that is clearly all rim damage, or clearly all surface porosity, means the model learned that defect mode on its own.

If the clusters are coherent, name them in the boxes, then use cluster_assignments.csv as the starting point for stage-two labels. You are correcting a rough sort rather than labelling from scratch.

If they look like random mixtures, the model found one generic "wrongness" signal rather than distinct types. That is worth knowing before anyone labels several thousand images.

The images shown are the ones closest to each cluster centre — the most typical members. Outliers sit in the CSV but not on this page.
